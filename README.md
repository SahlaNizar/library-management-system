# 📚 School Library Management System with Student Reading Behaviour Analytics

A web-based School Library Management System developed as a Final Year Project for the Higher National Diploma in Information Technology (HND IT).

The system is designed to digitize school library operations and provide useful insights into student reading behaviour through borrowing-history analytics.

---

## 🎯 Project Overview

Traditional school libraries may depend on paper-based records for books, students, borrowing, returns and fines. This can make information difficult to search, update and analyze.

This project provides a centralized web-based system that manages library activities while analyzing student borrowing patterns to identify reading behaviour and support better library management.

### 📊 Reading Behaviour Analytics

The system analyzes student borrowing history to identify different reading patterns.

It identifies:

- **Active Readers** – Students who borrow 3 or more books during the current term
- **Disengaged Readers** – Students with no borrowing activity for 30 days and no active reservation
- **Overdue-Prone Readers** – Students with 3 or more overdue returns within six months

The system also provides analytics for:

- Most borrowed books
- Most borrowed genres
- Most active classes
- Peak borrowing periods
- Popular genres by grade level
